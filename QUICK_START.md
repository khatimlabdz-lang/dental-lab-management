# ⚡ Quick Start Guide - 5 Minutes Setup\n\n## 🎯 Goal\nGet the entire Dental Lab Management System running locally with **zero configuration**.\n\n---\n\n## 📋 Prerequisites (Install First)\n\nDownload and install these 3 things:\n\n1. **Docker Desktop** - [Download here](https://www.docker.com/products/docker-desktop)\n   - Includes Docker + Docker Compose\n   - Works on Windows, Mac, Linux\n\n2. **Git** - [Download here](https://git-scm.com/)\n   - For cloning the repository\n\n3. **Code Editor** (Optional but recommended)\n   - [VSCode](https://code.visualstudio.com/) (recommended)\n   - Or any text editor\n\n---\n\n## 🚀 Step-by-Step Setup (5 Minutes)\n\n### Step 1: Clone Repository\n\n```bash\ngit clone https://github.com/khatimlabdz-lang/dental-lab-management.git\ncd dental-lab-management\n```\n\n### Step 2: Copy Environment Files\n\n```bash\ncp backend/.env.example backend/.env\ncp frontend/.env.example frontend/.env\n```\n\n**That's it! No configuration needed.**\n\n### Step 3: Start Everything with Docker\n\n```bash\ndocker-compose up -d\n```\n\nThis starts:\n- ✅ PostgreSQL Database\n- ✅ Redis Cache\n- ✅ MinIO File Storage\n- ✅ Backend API\n- ✅ Frontend App\n\n### Step 4: Wait for Services to Start\n\n```bash\n# Check if all services are running\ndocker-compose ps\n```\n\nExpected output:\n```\nNAME                 STATUS\ndentel-lab-db       Up (healthy)\ndentel-lab-cache    Up (healthy)\ndentel-lab-storage  Up\ndentel-lab-api      Up\ndentel-lab-web      Up\n```\n\n**Wait 30-60 seconds for all services to be ready.**\n\n### Step 5: Access the Application\n\nOpen your browser and go to:\n\n- 🖥️ **Frontend**: http://localhost:3001\n- 📡 **Backend API**: http://localhost:3000/api/v1\n- 💾 **MinIO Storage**: http://localhost:9001 (admin/admin)\n\n✅ **You're Done!**\n\n---\n\n## 🔑 Default Credentials\n\n### Database (PostgreSQL)\n- **Host**: localhost:5432\n- **Username**: postgres\n- **Password**: postgres\n- **Database**: dental_lab\n\n### MinIO Storage\n- **URL**: http://localhost:9001\n- **Username**: minioadmin\n- **Password**: minioadmin\n\n### Backend API\n- **URL**: http://localhost:3000/api/v1\n- **No authentication** (in development mode)\n\n---\n\n## 📝 Common Commands\n\n### View Logs\n```bash\n# All services\ndocker-compose logs -f\n\n# Specific service\ndocker-compose logs -f backend\ndocker-compose logs -f frontend\n```\n\n### Stop Services\n```bash\n# Stop but keep data\ndocker-compose stop\n\n# Stop and remove everything\ndocker-compose down\n```\n\n### Start Again\n```bash\ndocker-compose up -d\n```\n\n### Fresh Restart (Remove All Data)\n```bash\ndocker-compose down -v\ndocker-compose up -d\n```\n\n### Check Database Connection\n```bash\n# Connect to PostgreSQL\ndocker exec -it dental-lab-db psql -U postgres -d dental_lab\n\n# List tables (in PostgreSQL prompt)\n\\dt\n\n# Exit\n\\q\n```\n\n---\n\n## 🧪 Test the API\n\n### Using curl (command line)\n\n```bash\n# Health check\ncurl http://localhost:3000/api/v1/health\n```\n\n### Using Postman\n1. Download [Postman](https://www.postman.com/)\n2. Create new request\n3. Enter: `GET http://localhost:3000/api/v1/health`\n4. Click Send\n\n### Using Browser\nJust go to: http://localhost:3000/api/v1/health\n\n---\n\n## 🔧 Troubleshooting\n\n### Problem: Port Already in Use\n\n**Error**: `Address already in use`\n\n**Solution**: Stop the service using that port\n\n```bash\n# Kill service on port 3000 (backend)\nlsof -i :3000\nkill -9 <PID>\n\n# Kill service on port 3001 (frontend)\nlsof -i :3001\nkill -9 <PID>\n\n# Kill service on port 5432 (database)\nlsof -i :5432\nkill -9 <PID>\n```\n\n### Problem: Services Won't Start\n\n**Solution**: Restart Docker\n\n```bash\n# Stop everything\ndocker-compose down\n\n# Remove containers\ndocker-compose rm -f\n\n# Start again\ndocker-compose up -d\n```\n\n### Problem: Database Connection Error\n\n**Solution**: Wait longer (database takes time to initialize)\n\n```bash\n# Check database logs\ndocker-compose logs postgres\n\n# Wait 30 seconds, then try again\n```\n\n### Problem: Frontend Not Loading\n\n**Solution**: Check frontend logs\n\n```bash\ndocker-compose logs frontend\n```\n\n### Problem: Can't Connect to Database from Local Machine\n\n**Solution**: Database is only accessible from inside Docker. To access from your machine:\n\n```bash\n# Use this connection string\npsql -h localhost -U postgres -d dental_lab -p 5432\n```\n\n---\n\n## 📚 Next Steps After Setup\n\n### 1.
